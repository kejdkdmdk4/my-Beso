# Cafe Shop Website

A modern, responsive website for a coffee shop with features for browsing menu items, viewing the gallery, reading customer testimonials, and contacting the shop.

## Features

- **Responsive Design**: Fully responsive layout that works on all devices
- **Modern UI**: Clean and attractive user interface with smooth animations
- **Menu System**: Categorized menu with filtering options
- **Authentication**: User registration and login system
- **Gallery**: Image gallery with lightbox functionality
- **Testimonials**: Customer reviews and ratings
- **Contact Form**: Form for customers to send messages
- **Performance Optimized**: Fast loading with optimized assets

## Setup and Installation

1. Clone the repository:
   ```
   git clone https://github.com/yourusername/cafe-shop.git
   ```

2. Navigate to the project directory:
   ```
   cd cafe-shop
   ```

3. Open `index.html` in your browser or set up a local server.
